# hh-concepts

This is Hooman's personal visual knowledge library.

When asked to explain, visualize, or understand any concept — read `template/DESIGN.md` and `template/SKILL.md` before doing anything. These define the design rules and the thinking process. They are non-negotiable.

## project structure

```
template/
  DESIGN.md     ← read this first, every time
  SKILL.md      ← read this second, every time
  template.html ← reference only, not a strict pattern
library/
  cs/           ← algorithms, CS theory, math
  work/         ← MAIA, MLOps, medical AI, infrastructure
  personal/     ← reflections, lessons, personal concepts
```

## output

Always produce a single self-contained `.html` file. Place it in the right `library/` subfolder — infer from the subject. Never ask Hooman which folder unless genuinely ambiguous.

## working style

- Hooman is a visual thinker — comprehension through visuals, not text
- he iterates — the first attempt is rarely final, expect feedback
- he prefers honest pushback over blind execution — if the form is wrong, say so
- source material given by Hooman is ground truth — do not supplement with assumptions
- be creative for each subject — do not repeat the same visual structure twice
