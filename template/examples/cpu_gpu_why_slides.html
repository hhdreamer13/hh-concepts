A CPU has a few powerful cores.
A GPU has thousands of simple ones.
CPU — 4 cores
each core can do anything — logic, decisions, arithmetic
GPU — 4096 cores
each core can only multiply and add — but there are thousands
A CPU core is a generalist — it handles complex branching logic, memory management, anything. A GPU core is a specialist — it only does arithmetic. The tradeoff: fewer powerful vs many simple.

Give both one cell to compute. One core picks it up, does the work. Same speed. With a single task there is no advantage to having thousands of cores.
3 of 5
Sixteen tasks. The gap appears.
CPU — queues them
task 1 of 16...
GPU — all at once
16 cores assigned...
The CPU puts 16 tasks in a queue. One at a time. The GPU assigns one core per task — all 16 run simultaneously. GPU finishes in one step. CPU takes sixteen.
4 of 5
Why can all cells run at once?
Each one only needs its own inputs.
output cell (1,2)
needs: row 1 of A, column 2 of B
output cell (3,0)
needs: row 3 of A, column 0 of B
Each output cell only reads its own row and column. It never reads another output cell. So no cell needs to wait for any other cell — they are completely independent. This is what makes parallel computation possible.
5 of 5
So the GPU doesn't work faster.
It works less.
CPU — 16 steps
GPU — 1 step
The GPU core is not faster than the CPU core. Each one does the same arithmetic at similar speed. The difference: the GPU does all 16 cells in one moment instead of 16 moments. For a real model with million-cell matrices, this is the difference between hours and seconds.
